ESTRUCTURA

- blog.html: índice del blog.
- blog/: una página HTML independiente por cada artículo.
- assets/logo-balance-administrativo.jpg: logotipo de la empresa.

CÓMO PROBAR LOCALMENTE
1. Extrae el ZIP completo.
2. No cambies la estructura de carpetas.
3. Abre index.html en Chrome.
4. En móvil, toca el botón de tres líneas para desplegar el menú.
5. Abre Blog; cada fotografía, título y enlace de lectura lleva al artículo correspondiente.

CÓMO SUBIR A GITHUB PAGES
Sube el CONTENIDO de esta carpeta a la raíz de la rama que GitHub Pages publica:
index.html, blog.html, las carpetas blog/ y assets/.
No subas la carpeta externa contenedora. Conserva las rutas relativas.

CORREO DE COTIZACIONES
El botón de correo genera un borrador dirigido a info@balanceadministrativo.com mediante mailto.
La persona debe revisar y enviar el mensaje desde su aplicación de correo. GitHub Pages no procesa ni envía correos por sí solo; para un formulario de envío automático se necesita un servicio de formularios o un backend.
